서비스 안내

도어락, 이런 일을 합니다

매장에서 고르셔도 되고, 출장 때 실물을 가져가 현장에서 골라도 됩니다.

  1. 도어락 교체 설치

    쓰던 도어락을 떼고 새 제품을 답니다. 떼어 낸 제품은 원하시면 수거해 갑니다.

  2. 문 잠김 개문

    배터리 방전이나 고장으로 안 열릴 때 문을 부수지 않는 방법부터 시도합니다. 본인 확인 후 진행합니다.

  3. 번호·지문·카드 등록

    이사 후 비밀번호 초기화, 가족 지문 추가, 분실 카드 삭제를 해 드립니다.

  4. 보조키 추가 · 작동 불량 점검

    주키는 그대로 두고 보조키를 더 달거나, 헛도는 잠금·경고음을 점검합니다.

작업 과정

문 사진 두 장이면 시작됩니다

문 옆면과 안쪽 사진을 보내 주시면 대부분 맞는 모델을 미리 고를 수 있습니다.

  1. 사진으로 상담

    문 옆면·안쪽 사진으로 두께와 기존 구멍을 확인합니다.

  2. 모델·금액 안내

    맞는 모델 두세 가지와 설치 금액을 말씀드립니다.

  3. 방문 설치

    기존 제품을 떼고 새 도어락을 단단히 고정합니다.

  4. 등록·작동 확인

    번호·지문을 등록하고 여러 번 여닫아 확인합니다.

자주 묻는 질문

전화로 많이 받는 질문

문을 열어 드릴 때 본인 확인은 어떻게 하나요?

신분증 주소와 출장 주소가 같은지 확인합니다. 다르면 임대차계약서나 관리사무소 확인을 받은 뒤 진행하고, 확인이 안 되면 열어 드리지 않습니다.

쓰던 도어락 구멍을 그대로 쓸 수 있나요?

기존 타공과 맞는 모델이 있으면 그대로 씁니다. 문 사진을 보내 주시면 맞는 모델을 미리 골라 둡니다.

배터리가 다 돼서 문이 안 열려요.

바깥쪽 아래 비상 전원 단자에 9V 배터리를 대면 잠깐 전원이 들어옵니다. 그래도 안 되면 개문 출장을 불러 주세요.

방화문에도 달 수 있나요?

달 수 있습니다. 방화문은 타공을 최소로 하는 것이 좋아 기존 구멍을 쓰는 모델을 먼저 권해 드립니다.

설치는 얼마나 걸리나요?

기존 구멍을 그대로 쓰는 교체는 보통 한 시간 안에 끝납니다. 추가 타공이나 보조키 설치가 있으면 조금 더 걸립니다.
